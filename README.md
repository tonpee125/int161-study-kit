# INT161 · คู่มือและตัวอย่าง API

ชุดออฟไลน์สำหรับฝึก Express.js และ MySQL พร้อมตัวอย่างโจทย์ โค้ด และวิธีทดสอบ

## เปิดใช้

1. กด **Code → Download ZIP** แล้วแตกไฟล์
2. ดับเบิลคลิก **00-เปิดเลือกชุด.html**
3. เลือก **01-ของผม** แล้วกด **เริ่มทำทีละขั้น**

เปิดอ่านได้โดยไม่ใช้ Live Server หรือต่ออินเทอร์เน็ต หน้า HTML ต้องเปิดจากไฟล์ที่แตก ZIP แล้ว ไม่ใช่หน้าแสดงซอร์สบน GitHub

## มีอะไรบ้าง

- **01-ของผม** — เว็บเลือกโจทย์ ตัวอย่างการกรอก สะสมโค้ด ชุดเริ่มพร้อมใช้ และ Week 8
- **02-เพื่อนชุด (2)** — คู่มือและโค้ดต้นฉบับของเพื่อน
- **03-เพื่อนชุด (3)** — อีกชุดของเพื่อน พร้อมเอกสารประกอบ

เว็บของเรามีปุ่ม **ดูของเพื่อน** และปุ่มกลับหน้าหลัก

## ถ้าจะรัน API

เตรียม Node.js, MySQL และ Postman ติดตั้งแพ็กเกจด้วย `npm ci` ก่อนออฟไลน์ และนำเข้า SQL ของโจทย์เอง จากนั้นตั้งค่า MySQL กับรหัสของคุณตามคู่มือ

ตัวอย่างต้องปรับ schema, validation และ JSON ให้ตรงโจทย์จริง ไม่ใช่เฉลยที่ใช้แทนได้ทุกงาน การใช้งานในคาบหรือการสอบให้เป็นไปตามที่ผู้สอนอนุญาต
