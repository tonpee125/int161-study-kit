01-FIRST-TASK.md
# งานแรก — GET /countries บนเทมเพลตครู
โจทย์ฝึกนี้มาจากบทสอน Sakila ไม่ใช่ยืนยันว่าข้อสอบจริงใช้countryหรือฐานsakila
เป้าหมายรอบนี้: ใช้ app.js/route.js/service.js/repository.js ที่ครูให้แล้ว GET รายการได้
ไม่ต้องอ่านทั้งคู่มือก่อนทำ

## 1 เปิดโปรเจกต์ให้ถูก
เปิด01-WORK/node-express-esm-template ที่เห็นpackage.jsonกับsrc อย่าเปิดทั้งDesktopหรือเฉพาะsrc
รัน npm install ขณะอนุญาตให้ต่อเน็ต packageครูมี express,http-status,mysql2 ไม่มีstart script

## 2 เชื่อมฐานก่อน
เปิด src/configs-$id/db-config.js ของ01-WORK เปลี่ยนสี่ค่า db-host,db-username,db-password,database-name
ตัวอย่าง host localhost, userตามเครื่อง, passwordของMySQLเครื่องนั้น, database sakila
เปิด WebStorm Database → + → Data Source → MySQL ใช้ค่าเดียวกันกดTest Connection ต้องผ่าน
เปิด Query Console รัน SELECT country_id,country FROM sakila.country LIMIT 1;
ถ้าไม่มีsakilaให้ใช้SQLที่ครูให้หรือเตรียมSakilaก่อนฝึก อย่าเดาชื่อตารางหรือล้างฐานข้อมูลอื่น

## 3 เปิด repository.js ของครู — เปลี่ยนเฉพาะ findAll
เปิด src/repositories-$id/repository.js เปลี่ยน TABLE_NAME จาก table-name เป็น country
แทนฟังก์ชัน findAll เดิมด้วย:
```js
export async function findAll(pagination) {
    const [rows] = await db.query('SELECT * FROM country ORDER BY country_id');
    return rows;
}
```
ยังไม่ต้องแก้findOne/create/update/removeเพื่อทดสอบGETรายการ ถ้าจะทำเส้นเหล่านั้นเปิดชุดsakilaใน02-ANSWERS

## 4 เปิด service.js — ใช้ getAllObjects เดิมได้
src/services-$id/service.js มี getAllObjects เรียก await repo.findAll และ returnอยู่แล้ว ใช้ได้สำหรับรายการraw
รอบนี้ยังไม่ใช้getObjectซึ่งmapperต้นฉบับเป็นproduct DTO ไม่ใช่country

## 5 เปิด route.js — เปลี่ยนเฉพาะ GET /
ใน src/routes-$id/route.js แทนเฉพาะ router.get("/",...) ก้อนแรกด้วย:
```js
router.get('/', async (req, res) => {
    const objects = await service.getAllObjects();
    res.json(objects);
});
```
อย่าเพิ่มGET/ใหม่ซ้ำใต้ก้อนplaceholderเดิม เพราะก้อนแรกจะตอบก่อน

## 6 เปิด app.js — เปลี่ยน mount และเติม handler ว่าง
เปลี่ยน app.use('/', productRouter) เป็น app.use('/countries', productRouter)
แทน app.use((err,req,res,next)=>{}) ว่างด้วย:
```js
app.use((err, req, res, next) => {
    console.error(err);
    res.status(err.statusCode || 500).json({error: err.code || 'SERVER_ERROR', message: 'Request failed'});
});
```
นี่เป็นhandlerขั้นต่ำกันrequestค้างสำหรับGETแรก ไม่ใช่เฉลยerrorทุกกรณี; ชุดเต็ม02มีerror-handlerที่map404/400/409ตามโจทย์
app.listen3000เดิมเก็บไว้ ไม่เพิ่มserver.js ไม่listenซ้ำ

## 7 รันและตรวจ
Terminal Alt+F12 ที่รากโปรเจกต์ → node src/app.js
ต้องเห็น Example app listening on port 3000 ปล่อยTerminalนี้ทำงานอยู่
Postman desktop: GET http://localhost:3000/countries Body none → Send
ผล200และJSON arrayเทียบข้อมูลจริงในcountry ไม่ใช่ข้อความPlease write...
ถ้าerrorใช้06-RECOVERYตามข้อความ; ห้ามRun src/test-service.js

## 8 ต่อเส้นอื่นเมื่อGETแรกผ่าน
เปิด02-ANSWERS/sakila/HOW-TO.md และCODE.md เพื่อเติม GET/:id,POST,PUT,DELETE
แต่ละไฟล์ยังชื่อเดิมของครู เพิ่มactorเฉพาะเมื่อทำcountryผ่านแล้วตาม04-ADD-RESOURCE

02-READ-QUESTION.md
# ถอดโจทย์ก่อนเลือกทาง
ไม่ต้องพิมพ์คำถามให้เอกสารเข้าใจ ให้วางโจทย์ไว้ข้างคู่มือนี้แล้วคัดข้อความจริง

| ช่องที่ต้องเติม | ดูจากไหน | ตัวอย่าง | ถ้าไม่พบ |
|---|---|---|---|
| Method | GET/POST/PUT/DELETE หน้าหัวข้อ | POST | อ่านหัวข้อเพิ่ม/อ่าน/แก้/ลบ แล้วตรวจ endpoint อีกครั้ง |
| URL ทั้งเส้น | Method & URI / Endpoint | /api/YOUR_STUDENT_ID/productlines | ดูการ mount router ใน app.js ด้วย |
| ค่าหลัง : | เช่น :officeCode | officeCode | ถ้าไม่มีอาจเป็นรายการ ไม่ใช่รายตัว |
| ชื่อตารางจริง | Resource และ CREATE TABLE | productlines | เปิด SQL หรือหน้าต่าง Database |
| ชื่อคีย์และชนิด | PRIMARY KEY และชนิดคอลัมน์ | productLine VARCHAR(50) | SHOW CREATE TABLE ชื่อตาราง; |
| สร้างรหัสเองไหม | AUTO_INCREMENT | ไม่มี → รับจาก Body | ห้ามอนุมานจากชื่อ id |
| ช่องรับเข้า | Request Body และเงื่อนไข | productLine,textDescription | อย่าใช้ response แทน request |
| ช่องตอบกลับ | Response Body / DTO | id,name,price | แยกชื่อ JSON ออกจากชื่อ SQL |
| query | Query Parameters | page,limit,view | ไม่มีข้อกำหนดอย่าเติมฟีเจอร์เอง |
| สำเร็จ | Response Status | 201 | ดูสเปก ไม่คัด default จาก template |
| ล้มเหลว | เงื่อนไข/JSON error | 400/404/409 | จด code และ message ตามโจทย์ |
| รูปห่อ JSON | ตัวอย่างทั้งก้อน | status หรือ success | เปิด 07-AUDIT.md |

## ตัวอย่างถอดงานครู
Week 6 เพิ่ม productline: POST; ตาราง productlines; PK productLine เป็นข้อความ; Body ส่ง PK มาเอง; ชื่อว่าง 400; ซ้ำ 409; สำเร็จ 201 → classic
Week 6 payment: POST; customerNumber มาจาก URL, checkNumber มาจาก Body; คีย์คู่; ตรวจลูกค้าก่อน; amount > 0; วันที่ YYYY-MM-DD → classic
Week 8 รายการสินค้า: GET; page/limit; response data เป็น array เฉพาะ summary; pagination.total ต้องนับทุกแถว ไม่ใช่ความยาวของหน้านี้ → mobile
Sakila country: ตาราง country แต่ URL countries; PK country_id ไม่ใช่ id; country_id/last_update ไม่ต้องส่งตอนเพิ่ม → sakila

## อ่านไม่เข้าใจ ให้เริ่มจากรูปแทนศัพท์
- data: [...] = หลายรายการ; data: {...} = รายตัว; ดูเงื่อนไขประกอบ ไม่ใช่ตัดสินจากรูปเพียงอย่างเดียว
- :id ไม่ใช่ข้อความที่พิมพ์ส่งจริง เช่น /products/12 ไม่ใช่ /products/:id
- ?page=2&limit=10 คือ query; /products/12 คือ path; {...} ใต้ Request Body คือ body
- brand_name ไม่มีใน products แต่ response ต้องมี → ดู FK brand_id และตาราง brands ก่อนเปิดชุด JOIN
- ถ้าสเปกกับตัวอย่างขัดกัน ให้จดจุดขัดกันแล้วสอบถามผู้คุม/ครูตามช่องทางที่อนุญาต ไม่ใช้ความเคยชินตัดสิน

## ยืนยันก่อนคัดลอก
เขียนประโยค: ฉันทำ [METHOD] [URL] อ่าน/เขียน [TABLE] ด้วยคีย์ [KEY] รับ [BODY] คืน [FIELDS] สำเร็จ [STATUS] ผิดพลาด [CODES]
ถ้ายังเติมไม่ได้ ให้กลับดูสเปกหรือ SQL จุดนั้นก่อน ไม่สุ่มเลือกชุด

04-ADD-RESOURCE.md
# ทำข้อใหม่โดยไม่ลบข้อที่ผ่าน — ตัวอย่างcountryต่อactor
ไฟล์ครู generic repository.js/service.js/route.js ใช้เป็นcountryชุดแรก เมื่อทำคนละตารางเพิ่มชื่อไฟล์ใหม่ได้

## เพิ่มเพียง3ไฟล์
1. คัด repositories-$id/repository.js → actor-repository.js เปลี่ยน TABLE_NAME=actor, KEYในWHERE=actor_id, writable first_name,last_name
2. คัด services-$id/service.js → actor-service.js เปลี่ยนimportไปactor-repository.js และตรวจfirst_name,last_name
3. คัด routes-$id/route.js → actor-route.js เปลี่ยนimportไปactor-service.js
4. ในapp.jsเพิ่ม import actorRouter from './routes-$id/actor-route.js';
5. เพิ่ม app.use('/actors',actorRouter); หลังexpress.jsonและก่อนnot-found/error handler
6. mount '/countries' เดิมอยู่ครบ เปิดCODEของsakilaเพื่อดูไฟล์ทั้งหกกับapp.jsที่รวมถูกแล้ว
7. restart → GET/countriesต้องยัง200 → POST/actors → PUT/actors/รหัสใหม่ → DELETE →GET404

## ถ้าครูให้prefixรหัสนักศึกษา
app.use('/api/รหัสตัวเอง/countries',productRouter) กับ app.use('/api/รหัสตัวเอง/actors',actorRouter)
routerภายในยัง / และ /:id ไม่เขียนprefixซ้ำสองชั้น
ตัวอย่างSakilaในบทสอนไม่มีprefixนี้ ต้องดูข้อสอบจริง

## ห้ามทำ
อย่าแทนrepository.jsของcountryด้วยSQLactorโดยยังmountcountryเดิม ไม่เช่นนั้น/countriesจะตอบactor
อย่าแทนapp.jsทั้งไฟล์เมื่อมีงานอื่นแล้ว คัดเฉพาะimportและmount
ไม่เพิ่มdependency ไม่เปลี่ยนฐานข้อมูล/constraintเพื่อหลบerror ไม่listenซ้ำ

05-POSTMAN.md
# ทดสอบด้วย Postman แบบอ่านผลเป็น
ใช้ desktop สร้าง HTTP request ได้แม้ไม่ได้บันทึก Collection หน้าตาแต่ละเวอร์ชันอาจต่างกัน ให้ฝึกแบบออฟไลน์ก่อนสอบ
1. เปิด request เลือก Method ให้ตรงโจทย์
2. ใส่ URL เต็ม เช่น http://localhost:3000/api/YOUR_STUDENT_ID/products เปลี่ยนรหัสเป็นของตัวเอง
3. GET รายการ: Params ใส่ page=1 และ limit=10 เฉพาะเมื่อมี pagination อย่าใส่ซ้ำใน URL กับตาราง Params
4. GET รายตัว: แทน :id ด้วยรหัสจริง Body none
5. POST/PUT: Body → raw → JSON ตรวจ Headers มี Content-Type: application/json
6. คัดเฉพาะ JSON จริง ห้าม comments, ... หรือ comma ตัวท้าย ตัวเลขไม่ใส่เครื่องหมายคำพูดหากโจทย์กำหนด number
7. กด Send ดู status + body + ข้อมูลจริง ไม่ดูแค่ 200
8. เมื่อแก้โค้ด Ctrl+C ที่ terminal ของแอปแล้วรันใหม่ เว้นแต่ใช้ watch ที่ทำงานอยู่จริง

## ลำดับทดสอบที่ใช้ซ้ำได้
GET รายการ → GET id ที่มี → GET id ที่ไม่มี → POST ใหม่ → จดรหัสที่ response คืน → GET รหัสนั้น → PUT รหัสนั้น → GET ยืนยันค่า → PUT ค่าเดิม → DELETE รหัสนั้น → GET รหัสนั้นต้อง 404 → DELETE ซ้ำตามสเปก
ใช้เฉพาะข้อมูลทดลองที่เพิ่มเอง อย่าคัดเลข 110 จากรูป ตัวเลขอาจข้ามเมื่อ insert ล้มเหลว

| ชุด | Request ทดสอบ | คาดหวัง |
|---|---|---|
| sakila | POST /countries body {"country":"GuidePractice"} | 201 และ result.country_id เก็บเลขไว้ |

14-GENERAL-SEARCH.md
# คู่มือทั่วไปและช่องค้นหาออฟไลน์

เปิด START-TREE.html แล้ววางข้อความโจทย์ในช่องด้านบน กดค้นหา หรือเลือก GET / POST / PUT / DELETE ผลค้นหามาจากคำสำคัญในดัชนีที่เตรียมไว้ ไม่ใช้ AI ไม่มี API และไม่ส่งข้อความออกนอกเครื่อง

มีตัวอย่างทั่วไป 28 แบบ พร้อมโค้ดครบ 7 ไฟล์ต่อแบบ แยก repository / service / route และไฟล์ร่วมตามโครงเทมเพลตกลางภาค แต่ละหน้าบอกวิธีเปลี่ยนชื่อตาราง คีย์ ช่อง Body ชื่อ DTO และ URL เป็นของงานตน กล่องโค้ดมีปุ่มคัดลอก ถ้าเบราว์เซอร์ไม่อนุญาต clipboard จะเลือกข้อความให้แล้วกด Ctrl+C ได้

กรณีทำหลายข้อในไฟล์เดียว อย่าคัด run/read ซ้ำชื่อ ให้ตั้งชื่อฟังก์ชันแยกและแก้การเรียกทั้งสามชั้น หากมีงานเดิมอย่าคัดไฟล์เต็มทับ งานครูเดิมและหน้า Week8 ยังอยู่เป็นตัวอย่างสำหรับเทียบ

ผลตรวจ: ตัวอย่างทั่วไปทั้ง28แบบผ่าน HTTP กับ MySQL แยกสำหรับทดสอบ117 assertions รวมคีย์เลข/ข้อความ/คีย์ร่วม JOIN DTO การแบ่งหน้า การเพิ่ม การแก้ค่าคงเดิม ค่า0 การลบ ข้อมูลซ้ำ409 และ FKลบไม่ได้409 ส่วนหน้าเว็บตรวจครบ160หน้า ลิงก์ภายใน การค้นหา ปุ่มคัดลอก และขนาดหน้าจอมือถือ ไม่มี request ออกอินเทอร์เน็ต

มีJavaScriptในหน้าเว็บสำหรับค้นหาคำสำคัญและคัดลอกข้อความเท่านั้น ส่วนโค้ดAPIเป็นตัวอย่างที่เตรียมไว้ ผู้ใช้ยังต้องตรวจเทียบสเปกจริง ระบบไม่เข้าใจทุกประโยค ไม่ปรับschemaให้อัตโนมัติ และไม่รับรองโจทย์นอกเนื้อหาที่มี


ปรับการค้นหา: แยกMethod ทรัพยากร และเงื่อนไข เช่นรายตัว/แบ่งหน้า/DTO/JOIN/ส่งครบหรือบางช่อง รองรับหัวข้อใหญ่Products APIและBrands APIโดยแสดงหมวดรวมแทนการเดาข้อย่อย ตรวจ151ข้อความ รวม32ส่วนโจทย์จริงจากWeek8ทั้ง4ไฟล์ และตัวอย่างถอดความของทุกสูตรทั่วไป/endpointอ้างอิง ทั้งหมดผ่าน ระบบแจ้งเมื่อPUTยังไม่ระบุส่งครบหรือบางช่อง และDELETEยังไม่ระบุ200/204

16-STEP-BY-STEP.md
# ทำทีละขั้น พร้อมสะสมโค้ด

เปิด STEP-BY-STEP.html ด้วยเบราว์เซอร์ ไม่ต้องรันเซิร์ฟเวอร์เพื่อใช้หน้านี้

1. ทำตามหน้าเปิด WebStorm แล้วเลือกสำเนาเทมเพลตกลางภาค
2. กรอกชุดงาน MySQL และข้อมูลจากโจทย์
3. เปิด “สะสมโค้ดกับข้อก่อน” เลือกข้อ แล้วกดเพิ่ม
4. ดูไฟล์เต็มหลังรวม หรือส่วนที่เปลี่ยนในขั้นนี้ คัดลอกตามชื่อไฟล์ได้
5. กด “ทำข้อต่อไป” เพิ่มข้ออื่น เมื่อครบแล้วกด “เสร็จแล้ว · รวมทั้งหมด” และดาวน์โหลด ZIP

มี56ตัวเลือกจากสูตรทั่วไป28แบบ งานครู24กรณี และข้อระบุตัวตนของแต่ละชุด โดยแยกเป็นทั่วไป / Week8 / Week6 / Sakila เลือกชนิดงานหนึ่งชุดต่อโปรเจกต์ หาก Method/URL ชนกันจะให้ยืนยันแทนเฉพาะข้อที่ชนหรือยกเลิก ไม่เปลี่ยนชุดเดิมก่อนเลือก

โค้ดแต่ละข้อมีขอบเขตของตนเพื่อไม่ให้ชื่อฟังก์ชันซ้ำ และเรียง route ตายตัวก่อน route พารามิเตอร์ เช่น /items/count ก่อน /items/:id

การสะสมรวมเฉพาะข้อที่เลือกในหน้าเว็บ ไม่อ่านโค้ดที่แก้เองใน WebStorm หากแก้ไฟล์เองเพิ่มเติมต้องเก็บส่วนนั้นก่อนคัดทับ โหมดทั่วไปเปลี่ยนชื่อตาราง/คีย์/ช่องตัวอย่างได้ ส่วน schema หรือกฎอื่นที่ต่างต้องปรับตามโจทย์

แผนจำในเบราว์เซอร์เมื่อระบบอนุญาต และดาวน์โหลด/เปิดแผนJSONทำต่อได้ รหัสผ่านMySQLและSecret Keyไม่ถูกเก็บในแผนหรือlocalStorage ต้องกรอกใหม่หลังโหลดหน้า ส่วนZIPโค้ดมีค่าเชื่อมต่อที่กรอกไว้จริง จึงเก็บไฟล์เป็นของตน

ผลตรวจ: 56ตัวเลือกอิสระและชุดสะสมรวม101snapshot ผ่านการตรวจ863โมดูล; APIของโค้ดรวมชุดครูผ่าน63จุดและทางเลือก10จุด; สูตรทั่วไปผ่าน117จุด; เพิ่มทีละข้อจริง14ขั้นผ่าน86จุดโดยendpointก่อนยังทำงาน รวมถึงคีย์ชื่อdataและการเรียงcountก่อนid ตรวจบนMySQLแยกพอร์ต33071 ไม่เชื่อมฐานผู้ใช้พอร์ต3306

ตรวจหน้าเว็บ: เพิ่ม8ข้อWeek8, แทน/ยกเลิกข้อที่ชน, ปิดสะสมเพื่อดูตัวอย่างเดี่ยว, ย้อนดูแต่ละขั้น, โหลดหน้าและเปิดแผนทำต่อ, คัดลอกและดาวน์โหลดZIP, หน้าจอมือถือ และไม่มีrequestออกอินเทอร์เน็ต

หน้านี้เป็นโปรแกรมประกอบตัวอย่างที่เตรียมไว้ ไม่ใช้AI ไม่อ่านโจทย์ใหม่เพื่อสร้างคำตอบอัตโนมัติ และไม่รับรองschemaหรือข้อกำหนดที่ยังไม่ได้ปรับตามโจทย์จริง

### src/middlewares-$id/error-handler.js
```js
export class AppError extends Error {
 constructor(message,statusCode,errorCode){super(message);this.statusCode=statusCode;this.errorCode=errorCode;}
}
// แปลงข้อผิดพลาดเป็น HTTP/JSON ที่คาดเดาได้ เช่น SKUซ้ำ409, ข้อมูลอ้างอิงไม่มี400
export function errorHandler(err,req,res,next){
 if(res.headersSent)return next(err);
 let status=err.statusCode || err.status || 500, code=err.errorCode || 'INTERNAL_SERVER_ERROR',message=err.message;
 if(err.type==='entity.parse.failed'){status=400;code='INVALID_JSON';message='Invalid JSON body';}
 // MySQLแจ้ง UNIQUEซ้ำ เช่นSKU → HTTP409 ตามโจทย์
 if(err.code==='ER_DUP_ENTRY'){status=409;code='DUPLICATE_KEY';message=err.publicMessage || 'Resource already exists';}
 // brand_id อ้างถึงแบรนด์ที่ไม่มี → HTTP400
 if(err.code==='ER_NO_REFERENCED_ROW_2'){status=400;code='FOREIGN_KEY_NOT_FOUND';message=err.publicMessage || 'Referenced record does not exist';}
 if(err.code==='ER_ROW_IS_REFERENCED_2'){status=409;code='RESOURCE_IN_USE';message=err.publicMessage || 'Resource is referenced by related records';}
 // บันทึกปัญหาฝั่งเซิร์ฟเวอร์ แต่ไม่ส่งรายละเอียด SQL/รหัสผ่านกลับให้ผู้ใช้
 if(status>=500){console.error(err);message='Internal server error';}
 const mode='mobile';
 if(mode==='classic')return res.status(status).json({status:'error',error:{code,message}});
 if(mode==='sakila')return res.status(status).json({status,error:code,message,resource:req.originalUrl,timestamp:new Date().toLocaleString('en-US')});
 return res.status(status).json({success:false,error:{code,message},timestamp:new Date().toISOString()});
}
```

### src/mappers-$id/api-response.js
```js
// {student-id} - {student-name}
// ห่อผลลัพธ์เป็น success/data/timestamp; status เป็นอาร์กิวเมนต์ตัวที่4 ส่วนตัวที่3คือpagination
export async function apiResponse(res, data, pagination = null, status = 200) {
    const mode = 'mobile';
    if (mode === 'sakila') return res.status(status).json(status === 201 ? {result: data} : data);
    if (mode === 'classic') return res.status(status).json({status: 'success', data});
    const response = {success: true, data, timestamp: new Date().toISOString()};
    if (pagination) {
        const {page, limit} = pagination;
        const total = data.totalItems;
        response.pagination = {total, page, limit, totalPages: Math.ceil(total / limit), hasNextPage: page * limit < total, hasPrevPage: page > 1};
    }
    return res.status(status).json(response);
}
```

## 3. แก้ app.js เฉพาะจุด
เก็บimport expressและการสร้างapp/express.json/listenเดิมไว้ ไม่เพิ่มlistenตัวที่สอง
เพิ่มimportนี้ด้านบนแทนerror-handlerตัวอื่นถ้าใช้ชุดนี้:
```js
// ใช้ AppError ระบุ status/code และ errorHandler รวมการตอบข้อผิดพลาด
import {AppError, errorHandler} from './middlewares-$id/error-handler.js';
```
ประกาศIDรหัสจากสเปกก่อนrouteหนึ่งครั้ง ถ้ามีแล้วเปลี่ยนเฉพาะค่า ไม่ประกาศซ้ำ:
```js
// เปลี่ยนเป็นรหัสในสเปกที่เลือก; รหัสนี้ต้องตรงกับ base path ใน Postman
const ID = 'YOUR_STUDENT_ID';
```
หาบรรทัด app.use ที่mount productRouter ของต้นฉบับ แล้วเปลี่ยนบรรทัดนั้นเป็น:
```js
// ต่อ prefix /api/รหัสนักศึกษา เข้ากับ paths ใน route.js อย่าเติม prefix ซ้ำใน Router
app.use(`/api/${ID}`, productRouter);
```
แทนerror middlewareว่างของครูด้วยก้อนนี้ที่ท้ายส่วนrouter ถ้ามีerror handlerอื่นที่กำลังตอบอยู่ให้ใช้เพียงตัวเดียวตามสเปกชุดนี้:
```js
// catch-all404 ต้องอยู่หลัง route ทั้งหมด มิฉะนั้นจะดัก request ก่อนถึงคำตอบ
app.use((req, res, next) => next(new AppError('Route not found', 404, 'ROUTE_NOT_FOUND')));
// error middleware อยู่หลัง routes และ catch-all เพื่อรับข้อผิดพลาดจากทุกข้อ
app.use(errorHandler);
```
ทุกapp.get/app.useของrouteที่จะเพิ่มภายหลังต้องอยู่ก่อนตัวตอบ404นี้ โค้ดข้อ2.1ที่เพิ่มไว้ก่อนหน้านี้ต้องอยู่ครบ

## 1. ตรวจรหัสที่ประกาศอยู่แล้ว

เปิด `src/app.js` หาบรรทัด `const ID = ...` เช่นใน ZIP Week8 ให้เปลี่ยนค่าเป็นรหัสในสเปกที่กำลังฝึก
ตัวอย่างรูปแบบบรรทัดนี้: แทน YOUR_STUDENT_ID ด้วยรหัสจริงก่อนรัน

```js
// เปลี่ยนเป็นรหัสในสเปกที่เลือก; รหัสนี้ต้องตรงกับ base path ใน Postman
const ID = 'YOUR_STUDENT_ID';
```

ถ้ามี const ID อยู่แล้ว ให้แก้บรรทัดเดิม ไม่ประกาศซ้ำ
ถ้าไม่มี ให้เพิ่มเพียงหนึ่งบรรทัดในระดับบนสุด ก่อน route ด้านล่าง
ถ้าใช้ตัวแปร studentId อยู่แล้ว ให้ใช้ชื่อนั้นแทน ID ในก้อน route ทั้งสองตำแหน่ง หรือใช้ ID ตามตัวอย่างให้ครบ อย่าใช้สลับกัน
เมื่อฝึกสเปก exam-spec-67130500001.md ใช้รหัส 67130500001; ถ้าใช้สเปกอีกไฟล์ให้ใช้รหัสของไฟล์นั้น

## 2. เพิ่ม route ก้อนนี้ในตำแหน่งที่กำหนด

วางหลัง `app.use(express.json())` และก่อน `app.listen(...)` รวมถึงก่อน middleware ที่ตอบ 404 หากมี
ไม่วางไว้ใน callback ของ app.listen หรือใน route อื่น
หากมี `/student-info` อยู่แล้ว ให้แทนเฉพาะ route นั้น ไม่เพิ่มซ้ำ
แทน YOUR_NAME และ YOUR_SECRET ด้วยค่าจากสเปกของตัวเอง

```js
// ข้อ2.1: routeระบุตัวตน ใช้ข้อมูลจากสเปกชุดเดียวกัน ไม่ต้อง query ฐานข้อมูล
app.get(`/api/${ID}/student-info`, (req, res) => {
    res.status(200).json({
        success: true,
        data: {
            studentId: ID,
            name: 'YOUR_NAME',
            secretKey: 'YOUR_SECRET'
        },
        timestamp: new Date().toISOString()
    });
});
```

ใช้ก้อนนี้ได้โดยไม่อ้างไฟล์ `routes-$id` หรือ `apiResponse` เพราะใช้ Express ที่ app.js เดิมมีอยู่แล้ว
การเปิดแอปอาจยังต้องมี dependencies ของเทมเพลตครบ แต่ route นี้ไม่จำเป็นต้องต่อ DB เพื่อสร้าง response
ไม่ต้องแก้ mount ของ offices/productlines/products เพื่อทำข้อ 2.1

บันทึก Ctrl+S หากแอปรันอยู่ให้ Ctrl+C ใน Terminal ของแอป แล้วรันใหม่จากรากโปรเจกต์:


## ตรวจเมื่อยังไม่ผ่าน

- 404: เทียบรหัสใน URL กับ ID, ตรวจตำแหน่ง route ว่าอยู่ก่อนตัวตอบ404, แล้ว restart
- ชื่อหรือ secretKey ไม่ตรง: เทียบข้อมูลในสเปกไฟล์ที่กำลังฝึก ไม่ใช้ข้อมูลของอีกคน
- ID has already been declared: มี const ID ซ้ำ ให้เหลือการประกาศเดิมเพียงครั้งเดียว
- ID is not defined: ยังไม่ประกาศ ID หรือใช้ชื่อ studentId อยู่ ให้ใช้ชื่อตรงกัน
- Import ไม่พบ: ย้อนคืนการคัด app.js ทั้งชุดกลางภาคถ้าเผลอทำไป แล้วเพิ่มเฉพาะ route ตามหน้านี้ในไฟล์ Week8
- ไม่เห็นผลเปลี่ยน: บันทึกไฟล์และหยุดแอปเก่าก่อนเปิดใหม่

# 2.3 (1) สินค้าแบ่งหน้า

## โจทย์จากใบงานครู

#### 1) [GET] รายการสินค้าแบบแบ่งหน้าและแปลง DTO (30 คะแนน)
* **Endpoint:** `/api/YOUR_STUDENT_ID/products`
* **Query Parameters:**
  * `page`: หมายเลขหน้า (เริ่มต้นที่ 1, ค่า default คือ 1)
  * `limit`: จำนวนรายการต่อหน้า (เช่น 10)
* **การแปลง DTO (Summary DTO):**
  ข้อมูลใน `data` จะต้องแสดงเฉพาะฟิลด์สรุป:
  * `id`
  * `sku`
  * `name`
  * `brandId` (หรือ `brand_id`)
  * `category`
  * `price`
  * `status`
* **Response Body:**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "sku": "APL-IP15PM-256-NT",
      "name": "iPhone 15 Pro Max",
      "brandId": 1,
      "category": "FLAGSHIP",
      "price": 48900.00,
      "status": "AVAILABLE"
    }
  ],
  "pagination": {
    "total": 75,
    "page": 1,
    "limit": 10,
    "totalPages": 8,
    "hasNextPage": true,
    "hasPrevPage": false
  },
  "timestamp": "2026-10-08T15:00:00.000Z"
}
```

## เข้าใจก่อนวางโค้ด

```js
 // Summary DTO ส่งเพียง7ช่อง ใช้กับGETรายการสินค้า ไม่ส่งสต็อก/สี/วันวางขายเกินโจทย์
```

```js
export async function findAll({limit,offset}){
```

### 4. src/middlewares-$id/pagination-middleware.js
แทนทั้งไฟล์นี้ หากมีข้อก่อนใช้อยู่ ให้ทดสอบข้อก่อนหลังแก้ด้วย
```js
// ใช้ AppError ระบุ status/code และ errorHandler รวมการตอบข้อผิดพลาด
import {AppError} from './error-handler.js';
// อ่าน page/limit จาก URL ตรวจจำนวนเต็มบวก แล้วคำนวณ offset=(page-1)*limit
export const queryParser = () => (req,res,next) => {
 // query เป็นข้อความ จึงตรวจรูปแบบก่อนแปลงเป็นตัวเลข ไม่ยอมรับ 2abc หรือค่าซ้ำแบบarray
 function positive(value,fallback){if(value===undefined)return fallback;if(typeof value!=='string'||! /^[1-9]\d*$/.test(value)||!Number.isSafeInteger(Number(value)))throw new AppError('Invalid pagination',400,'VALIDATION_ERROR');return Number(value);}
 const page=positive(req.query.page,1),limit=Math.min(positive(req.query.limit,10),100),offset=(page-1)*limit;
 if(!Number.isSafeInteger(offset))throw new AppError('Page too large',400,'VALIDATION_ERROR');
 req.pagination={page,limit,offset};next();
}
```

```js
function validate(p){
```

### 1. src/mappers-$id/entity-dto-mapper.js
แทนทั้งไฟล์นี้ หากมีข้อก่อนใช้อยู่ ให้ทดสอบข้อก่อนหลังแก้ด้วย
```js
// {student-id} - {student-name}
export default class EntityDtoMapper {
 // Summary DTO ส่งเพียง7ช่อง ใช้กับGETรายการสินค้า ไม่ส่งสต็อก/สี/วันวางขายเกินโจทย์
 static toSummaryDTO(p){return {id:p.id,sku:p.sku,name:p.name,brandId:p.brand_id,category:p.category,price:p.price,status:p.status};}
 // Detail DTO เพิ่มชื่อแบรนด์ RAM ความจุ สี สต็อก และวันวางขาย รวม13ช่อง
 static toDetailDTO(p){return {...this.toSummaryDTO(p),brandName:p.brand_name,ramGb:p.ram_gb,storageGb:p.storage_gb,color:p.color,stockQuantity:p.stock_quantity,releaseDate:p.release_date};}
 // เลือกชนิด DTO ตาม viewType ที่ service กำหนด
 static map(entity,viewType){return viewType==='summary'?this.toSummaryDTO(entity):this.toDetailDTO(entity);}
 // แปลงทุกแถวและเก็บ totalItems ไว้ใช้สร้าง pagination แม้ผลลัพธ์จะเป็น arrayว่าง
 static maps(entities,viewType){
  const data=entities.map(entity=>this.map(entity,viewType));
  if(entities.totalItems!==undefined)data.totalItems=entities.totalItems;
  return data;
 }
}
```

* **Status:** `204 No Content` (ไม่มี Response Body) หรือ `404 Not Found` หากไม่พบ ID

## เข้าใจก่อนวางโค้ด

ใช้ id ที่เพิ่งเพิ่มเอง ลบสำเร็จจบด้วย status204 และ end() จึงไม่มี JSON จากนั้น GET id เดิมต้อง404 และ DELETE ซ้ำต้อง404 อย่าใช้สินค้าตั้งต้นเพราะจะทำให้จำนวน seed ไม่ตรง

```js
// ห่อผลลัพธ์เป็น success/data/timestamp; status เป็นอาร์กิวเมนต์ตัวที่4 ส่วนตัวที่3คือpagination
export async function apiResponse(res, data, pagination = null, status = 200) {
    const mode = 'mobile';
    if (mode === 'sakila') return res.status(status).json(status === 201 ? {result: data} : data);
    if (mode === 'classic') return res.status(status).json({status: 'success', data});
    const response = {success: true, data, timestamp: new Date().toISOString()};
    if (pagination) {
        const {page, limit} = pagination;
        const total = data.totalItems;
        response.pagination = {total, page, limit, totalPages: Math.ceil(total / limit), hasNextPage: page * limit < total, hasPrevPage: page > 1};
    }
    return res.status(status).json(response);
}
```

### src/middlewares-$id/error-handler.js

```js
export class AppError extends Error {
 constructor(message,statusCode,errorCode){super(message);this.statusCode=statusCode;this.errorCode=errorCode;}
}
// แปลงข้อผิดพลาดเป็น HTTP/JSON ที่คาดเดาได้ เช่น SKUซ้ำ409, ข้อมูลอ้างอิงไม่มี400
export function errorHandler(err,req,res,next){
 if(res.headersSent)return next(err);
 let status=err.statusCode || err.status || 500, code=err.errorCode || 'INTERNAL_SERVER_ERROR',message=err.message;
 if(err.type==='entity.parse.failed'){status=400;code='INVALID_JSON';message='Invalid JSON body';}
 // MySQLแจ้ง UNIQUEซ้ำ เช่นSKU → HTTP409 ตามโจทย์
 if(err.code==='ER_DUP_ENTRY'){status=409;code='DUPLICATE_KEY';message=err.publicMessage || 'Resource already exists';}
 // brand_id อ้างถึงแบรนด์ที่ไม่มี → HTTP400
 if(err.code==='ER_NO_REFERENCED_ROW_2'){status=400;code='FOREIGN_KEY_NOT_FOUND';message=err.publicMessage || 'Referenced record does not exist';}
 if(err.code==='ER_ROW_IS_REFERENCED_2'){status=409;code='RESOURCE_IN_USE';message=err.publicMessage || 'Resource is referenced by related records';}
 // บันทึกปัญหาฝั่งเซิร์ฟเวอร์ แต่ไม่ส่งรายละเอียด SQL/รหัสผ่านกลับให้ผู้ใช้
 if(status>=500){console.error(err);message='Internal server error';}
 const mode='mobile';
 if(mode==='classic')return res.status(status).json({status:'error',error:{code,message}});
 if(mode==='sakila')return res.status(status).json({status,error:code,message,resource:req.originalUrl,timestamp:new Date().toLocaleString('en-US')});
 return res.status(status).json({success:false,error:{code,message},timestamp:new Date().toISOString()});
}
```

```js
// ใช้ AppError ระบุ status/code และ errorHandler รวมการตอบข้อผิดพลาด
import {AppError} from './error-handler.js';
// อ่าน page/limit จาก URL ตรวจจำนวนเต็มบวก แล้วคำนวณ offset=(page-1)*limit
export const queryParser = () => (req,res,next) => {
 // query เป็นข้อความ จึงตรวจรูปแบบก่อนแปลงเป็นตัวเลข ไม่ยอมรับ 2abc หรือค่าซ้ำแบบarray
 function positive(value,fallback){if(value===undefined)return fallback;if(typeof value!=='string'||! /^[1-9]\d*$/.test(value)||!Number.isSafeInteger(Number(value)))throw new AppError('Invalid pagination',400,'VALIDATION_ERROR');return Number(value);}
 const page=positive(req.query.page,1),limit=Math.min(positive(req.query.limit,10),100),offset=(page-1)*limit;
 if(!Number.isSafeInteger(offset))throw new AppError('Page too large',400,'VALIDATION_ERROR');
 req.pagination={page,limit,offset};next();
}
```

```js
// ชั้น service เรียก repository เพื่อแยก SQL ออกจากกฎการทำงาน
import * as repo from '../repositories-$id/repository.js';
// ใช้ mapper เลือกและเปลี่ยนชื่อช่องข้อมูลให้ตรง DTO ที่โจทย์ต้องการ
import mapper from '../mappers-$id/entity-dto-mapper.js';
// ใช้ AppError ระบุ status/code และ errorHandler รวมการตอบข้อผิดพลาด
import {AppError} from '../middlewares-$id/error-handler.js';
// ช่องที่สินค้าต้องมีเมื่อผ่านการเติมค่าเริ่มต้นแล้ว; ชื่อรับเข้าใช้ snake_case ตาม Bodyครู
const required=['sku','name','brand_id','category','price','ram_gb','storage_gb','color'];
// รายชื่อช่องที่ผู้ใช้แก้ได้ ไม่รับ id หรือช่องระบบจาก Body
const writable=[...required,'stock_quantity','status','release_date'];
// หยุดทำงานด้วย HTTP 400 เมื่อค่าที่รับเข้าไม่ถูกต้อง แล้วส่งต่อให้ errorHandler จัดรูป JSON
function fail(message){throw new AppError(message,400,'VALIDATION_ERROR');}
// รับเฉพาะ JSON object ป้องกัน null, array และชนิดข้อมูลที่ไม่ใช่ object
function object(body){if(!body||typeof body!=='object'||Array.isArray(body))fail('JSON object required');}
// เลือกเฉพาะช่องที่อนุญาตให้เขียน ไม่เอาทุกช่องจาก Body ไปสร้าง SQL โดยตรง
function pick(body){object(body);const data={};for(const key of writable)if(Object.hasOwn(body,key))data[key]=body[key];return data;}
// ตรวจข้อมูลก่อนบันทึก ทั้งช่องจำเป็น ชนิดข้อมูล ราคา สต็อก และวันที่
function validate(p){
 // ตรวจว่าไม่มีช่องจำเป็นหายไปหรือเป็น null
 for(const key of required)if(p[key]===undefined||p[key]===null)fail(`Field '${key}' is required`);
 // ช่องข้อความต้องเป็น string และไม่ว่าง
 for(const key of ['sku','name','category','color','status'])if(typeof p[key]!=='string'||!p[key].trim())fail(`Invalid ${key}`);
 // รหัสแบรนด์ RAM และความจุต้องเป็นจำนวนเต็มบวก
 for(const key of ['brand_id','ram_gb','storage_gb'])if(!Number.isSafeInteger(p[key])||p[key]<=0)fail(`Invalid ${key}`);
 // ราคาเป็นตัวเลขจริงที่ไม่ติดลบ ไม่รับข้อความหรือ NaN
 if(typeof p.price!=='number'||!Number.isFinite(p.price)||p.price<0)fail('Invalid price');
 // สต็อกต้องเป็นจำนวนเต็มตั้งแต่0ขึ้นไป
 if(!Number.isSafeInteger(p.stock_quantity)||p.stock_quantity<0)fail('Invalid stock_quantity');
 // ถ้าใส่วันวางขาย ต้องเป็น YYYY-MM-DD และเป็นวันที่มีจริง เช่นไม่รับ 2026-02-30
 if(p.release_date!==null){const s=p.release_date,d=new Date(s+'T00:00:00Z');if(typeof s!=='string'||!/^\d{4}-\d{2}-\d{2}$/.test(s)||!Number.isFinite(d.getTime())||d.toISOString().slice(0,10)!==s)fail('Invalid release_date');}
 return p;
}
// ค้นหาสินค้าก่อน ถ้าไม่พบโยน 404 เพื่อให้ GET/PUT/DELETE ตอบตรงโจทย์
async function existing(id){const row=await repo.findOne(id);if(!row)throw new AppError(`Product '${id}' was not found`,404,'PRODUCT_NOT_FOUND');return row;}
// ข้อ2.2(ก): ขอรายการแบรนด์ทั้งหมดจาก repository
export const getBrands=()=>repo.brands();
// ข้อ2.2(ข): ขอแบรนด์ตาม id ถ้าไม่พบตอบ404
export async function getBrand(id){const row=await repo.brand(id);if(!row)throw new AppError('Brand not found',404,'BRAND_NOT_FOUND');return row;}
// ข้อ2.3(1): อ่านสินค้าตาม pagination แล้วเลือก Summary DTO สำหรับรายการ
export async function getAllObjects(pagination){return mapper.maps(await repo.findAll(pagination),'summary');}
// ข้อ2.3(2): ตรวจว่าสินค้ามีจริงแล้วแปลงเป็น Detail DTO
export async function getObject(id){return mapper.toDetailDTO(await existing(id));}
// ข้อ2.3(3): เติมค่าเริ่มต้น ตรวจ Body แล้วเพิ่มสินค้าและตอบ Detail DTO ของรายการใหม่
export async function createObject(body){const data=validate({stock_quantity:0,status:'AVAILABLE',release_date:null,...pick(body)});return mapper.toDetailDTO(await repo.create(data));}
// ข้อ2.3(4): อ่านค่าเก่าก่อน ผสานเฉพาะช่องที่ส่งมา ตรวจแล้วอัปเดต
export async function updateObject(id,body){
 const old=await existing(id),patch=pick(body);if(!Object.keys(patch).length)fail('No writable fields');
 const data=validate({...pick(old),...patch});return mapper.toDetailDTO(await repo.update(id,data));
}
// ข้อ2.3(5): ตรวจว่ามีสินค้าก่อนลบ เพื่อแยกกรณี404จากการลบสำเร็จ
export async function removeObject(id){await existing(id);await repo.remove(id);}
```

# ใช้ชุด sakila บนเทมเพลตครู
ฐานคือ midterm-exam-esm-template.zip เดิม โฟลเดอร์ -$id คงตาม ZIP อย่าเปลี่ยนเป็น -guide

## กรณีเริ่มจากเทมเพลตว่าง ยังไม่มีข้อที่ทำไว้
1. ดูโจทย์ว่าตรงชุดนี้: country+actor CRUD บน Sakila
2. เปิด CODE.md คัดโค้ดตามชื่อไฟล์จากหัวข้อไปวางในไฟล์ชื่อเดียวกันใน01-WORK
3. เรียงการวาง: config → error-handler → api-response → mapper → pagination(ถ้าใช้) → repository → service → route → app
4. เฉพาะ db-config.js ให้ใส่ค่าของเครื่องเอง อย่าคัดทับค่าที่คุณตั้งใช้ได้แล้ว; คง decimalNumbers/dateStrings ตามชุด
5. app.js ใส่รหัส/ชื่อของคุณตามสเปก อย่าใช้ YOUR_STUDENT_ID ส่งงาน; Sakila บทสอนใช้ /countries ไม่ใช้ prefixนักศึกษา
6. รัน node src/app.js ไม่ใช่ npm start เพราะ packageครูไม่มีstart
7. ส่ง Postman ตามตาราง 05-POSTMAN.md ในรากคู่มือ แล้วตรวจresponseตามโจทย์

## กรณีทำข้อก่อนแล้ว
ห้ามคัด app.js ทั้งไฟล์ ให้เพิ่ม import/mount ของข้อใหม่ เก็บ express.json/routerเดิม/error handlerท้ายสุด
ถ้าเป็นตารางเดียวกัน เพิ่มเฉพาะฟังก์ชัน/route ที่ต้องใช้ อย่าแทน service/repository ทั้งไฟล์จนข้อเดิมหาย
หากคนละตาราง ใช้การคัดไฟล์เพิ่มแบบactor: repository/service/routeของresourceใหม่ แล้วเปลี่ยนimportเฉพาะคู่นั้น
ตัวอย่างครบการเพิ่มresourceโดยไม่ลบของเดิมอยู่ 04-ADD-RESOURCE.md

```js
// {student-id} - {student-name}
export async function apiResponse(res, data, pagination = null, status = 200) {
    const mode = 'sakila';
    if (mode === 'sakila') return res.status(status).json(status === 201 ? {result: data} : data);
    if (mode === 'classic') return res.status(status).json({status: 'success', data});
    const response = {success: true, data, timestamp: new Date().toISOString()};
    if (pagination) {
        const {page, limit} = pagination;
        const total = data.totalItems;
        response.pagination = {total, page, limit, totalPages: Math.ceil(total / limit), hasNextPage: page * limit < total, hasPrevPage: page > 1};
    }
    return res.status(status).json(response);
}
```

```js
export class AppError extends Error {
 constructor(message,statusCode,errorCode){super(message);this.statusCode=statusCode;this.errorCode=errorCode;}
}
export function errorHandler(err,req,res,next){
 if(res.headersSent)return next(err);
 let status=err.statusCode || err.status || 500, code=err.errorCode || 'INTERNAL_SERVER_ERROR',message=err.message;
 if(err.type==='entity.parse.failed'){status=400;code='INVALID_JSON';message='Invalid JSON body';}
 if(err.code==='ER_DUP_ENTRY'){status=409;code='DUPLICATE_KEY';message=err.publicMessage || 'Resource already exists';}
 if(err.code==='ER_NO_REFERENCED_ROW_2'){status=400;code='FOREIGN_KEY_NOT_FOUND';message=err.publicMessage || 'Referenced record does not exist';}
 if(err.code==='ER_ROW_IS_REFERENCED_2'){status=409;code='RESOURCE_IN_USE';message=err.publicMessage || 'Resource is referenced by related records';}
 if(status>=500){console.error(err);message='Internal server error';}
 const mode='sakila';
 if(mode==='classic')return res.status(status).json({status:'error',error:{code,message}});
 if(mode==='sakila')return res.status(status).json({status,error:code,message,resource:req.originalUrl,timestamp:new Date().toLocaleString('en-US')});
 return res.status(status).json({success:false,error:{code,message},timestamp:new Date().toISOString()});
}
```

```js
// {student-id} - {student-name}
export async function apiResponse(res, data, pagination = null, status = 200) {
    const mode = 'classic';
    if (mode === 'sakila') return res.status(status).json(status === 201 ? {result: data} : data);
    if (mode === 'classic') return res.status(status).json({status: 'success', data});
    const response = {success: true, data, timestamp: new Date().toISOString()};
    if (pagination) {
        const {page, limit} = pagination;
        const total = data.totalItems;
        response.pagination = {total, page, limit, totalPages: Math.ceil(total / limit), hasNextPage: page * limit < total, hasPrevPage: page > 1};
    }
    return res.status(status).json(response);
}
```

```js
export class AppError extends Error {
 constructor(message,statusCode,errorCode){super(message);this.statusCode=statusCode;this.errorCode=errorCode;}
}
export function errorHandler(err,req,res,next){
 if(res.headersSent)return next(err);
 let status=err.statusCode || err.status || 500, code=err.errorCode || 'INTERNAL_SERVER_ERROR',message=err.message;
 if(err.type==='entity.parse.failed'){status=400;code='INVALID_JSON';message='Invalid JSON body';}
 if(err.code==='ER_DUP_ENTRY'){status=409;code='DUPLICATE_KEY';message=err.publicMessage || 'Resource already exists';}
 if(err.code==='ER_NO_REFERENCED_ROW_2'){status=400;code='FOREIGN_KEY_NOT_FOUND';message=err.publicMessage || 'Referenced record does not exist';}
 if(err.code==='ER_ROW_IS_REFERENCED_2'){status=409;code='RESOURCE_IN_USE';message=err.publicMessage || 'Resource is referenced by related records';}
 if(status>=500){console.error(err);message='Internal server error';}
 const mode='classic';
 if(mode==='classic')return res.status(status).json({status:'error',error:{code,message}});
 if(mode==='sakila')return res.status(status).json({status,error:code,message,resource:req.originalUrl,timestamp:new Date().toLocaleString('en-US')});
 return res.status(status).json({success:false,error:{code,message},timestamp:new Date().toISOString()});
}
```

## src/services-$id/service.js
```js
import * as repo from '../repositories-$id/repository.js';
import {AppError} from '../middlewares-$id/error-handler.js';
function object(body){if(!body || typeof body!=='object' || Array.isArray(body))throw new AppError('JSON object required',400,'VALIDATION_ERROR');}
function fail(message,code='VALIDATION_ERROR'){throw new AppError(message,400,code);}
function dateOK(value){if(typeof value!=='string'||!/^\d{4}-\d{2}-\d{2}$/.test(value))return false;const d=new Date(value+'T00:00:00Z');return Number.isFinite(d.getTime())&&d.toISOString().slice(0,10)===value;}
export async function getOffice(id){const row=await repo.office(id);if(!row)throw new AppError(`Office with code '${id}' was not found`,404,'OFFICE_NOT_FOUND');return row;}
export async function createLine(body){
 object(body);
 if(typeof body.productLine!=='string'||!body.productLine.trim())fail("Field 'productLine' is required and cannot be empty");
 const data={productLine:body.productLine.trim()};
 if(data.productLine.length>50)fail('productLine must be at most 50 characters');
 if(Object.hasOwn(body,'textDescription')){if(body.textDescription!==null&&typeof body.textDescription!=='string')fail('Invalid textDescription');data.textDescription=body.textDescription;}
 try{return await repo.createLine(data);}catch(err){if(err.code==='ER_DUP_ENTRY')err.publicMessage=`Product line '${data.productLine}' already exists`;throw err;}
}
export async function updateEmployee(id,body){
 const old=await repo.employee(id);if(!old)throw new AppError(`Employee with ID '${id}' was not found`,404,'EMPLOYEE_NOT_FOUND');
 object(body);const data={};
 for(const key of ['firstName','lastName','email','officeCode','reportsTo','jobTitle'])if(Object.hasOwn(body,key))data[key]=body[key];
 if(!Object.keys(data).length)fail('No writable fields');
 if(Object.hasOwn(data,'email')&&(typeof data.email!=='string'||! /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(data.email)))fail('Invalid email address format','INVALID_EMAIL');
 for(const key of ['firstName','lastName','officeCode','jobTitle'])if(Object.hasOwn(data,key)&&(typeof data[key]!=='string'||!data[key].trim()))fail(`Invalid ${key}`);
 if(Object.hasOwn(data,'reportsTo')&&data.reportsTo!==null&&(!Number.isSafeInteger(data.reportsTo)||data.reportsTo<=0))fail('Invalid reportsTo');
 try{return await repo.updateEmployee(id,data);}catch(err){if(err.code==='ER_NO_REFERENCED_ROW_2')err.publicMessage='Invalid office code or reporting manager ID';throw err;}
}
export async function removeCustomer(id){
 if(!await repo.customer(id))throw new AppError(`Customer with ID '${id}' was not found`,404,'CUSTOMER_NOT_FOUND');
 try{await repo.removeCustomer(id);}catch(err){if(err.code==='ER_ROW_IS_REFERENCED_2')err.publicMessage='Cannot delete customer because related orders or payment records exist';throw err;}
 return {message:'Customer record successfully deleted'};
}
export async function createPayment(id,body){
 if(!await repo.customer(id))throw new AppError(`Customer with ID '${id}' was not found`,404,'CUSTOMER_NOT_FOUND');
 object(body);
 if(typeof body.amount!=='number'||!Number.isFinite(body.amount)||body.amount<=0)fail('Payment amount must be greater than zero','INVALID_PAYMENT_DATA');
 if(!dateOK(body.paymentDate))fail('Payment date must be YYYY-MM-DD','INVALID_PAYMENT_DATA');
 if(typeof body.checkNumber!=='string'||!body.checkNumber.trim()||body.checkNumber.length>50)fail('Invalid check number','INVALID_PAYMENT_DATA');
 const data={customerNumber:id,checkNumber:body.checkNumber,paymentDate:body.paymentDate,amount:body.amount};
 try{return await repo.createPayment(data);}catch(err){if(err.code==='ER_DUP_ENTRY')err.publicMessage=`Check number '${data.checkNumber}' has already been registered for this customer`;throw err;}
}
```

```js
import {AppError} from './error-handler.js';
export const queryParser = () => (req,res,next) => {
 function positive(value,fallback){if(value===undefined)return fallback;if(typeof value!=='string'||! /^[1-9]\d*$/.test(value)||!Number.isSafeInteger(Number(value)))throw new AppError('Invalid pagination',400,'VALIDATION_ERROR');return Number(value);}
 const page=positive(req.query.page,1),limit=Math.min(positive(req.query.limit,10),100),offset=(page-1)*limit;
 if(!Number.isSafeInteger(offset))throw new AppError('Page too large',400,'VALIDATION_ERROR');
 req.pagination={page,limit,offset};next();
}
```

```js
export async function apiResponse(res, data, pagination = null, status = 200) {
    const mode = 'mobile';
    if (mode === 'sakila') return res.status(status).json(status === 201 ? {result: data} : data);
    if (mode === 'classic') return res.status(status).json({status: 'success', data});
    const response = {success: true, data, timestamp: new Date().toISOString()};
    if (pagination) {
        const {page, limit} = pagination;
        const total = data.totalItems;
        response.pagination = {total, page, limit, totalPages: Math.ceil(total / limit), hasNextPage: page * limit < total, hasPrevPage: page > 1};
    }
    return res.status(status).json(response);
}
```

```js
 if(err.code==='ER_ROW_IS_REFERENCED_2'){status=409;code='RESOURCE_IN_USE';message=err.publicMessage || 'Resource is referenced by related records';}

 const mode='mobile';

 if(mode==='sakila')return res.status(status).json({status,error:code,message,resource:req.originalUrl,timestamp:new Date().toLocaleString('en-US')});
```

```js
export async function apiResponse(res, data, pagination = null, status = 200) {
    const mode = 'mobile';
    if (mode === 'sakila') return res.status(status).json(status === 201 ? {result: data} : data);
    if (mode === 'classic') return res.status(status).json({status: 'success', data});
    const response = {success: true, data, timestamp: new Date().toISOString()};
    if (pagination) {
        const {page, limit} = pagination;
        const total = data.totalItems;
        response.pagination = {total, page, limit, totalPages: Math.ceil(total / limit), hasNextPage: page * limit < total, hasPrevPage: page > 1};
    }
    return res.status(status).json(response);
}
```

```js
export function errorHandler(err,req,res,next){

 if(err.type==='entity.parse.failed'){status=400;code='INVALID_JSON';message='Invalid JSON body';}

 if(err.code==='ER_NO_REFERENCED_ROW_2'){status=400;code='FOREIGN_KEY_NOT_FOUND';message=err.publicMessage || 'Referenced record does not exist';}
 if(err.code==='ER_ROW_IS_REFERENCED_2'){status=409;code='RESOURCE_IN_USE';message=err.publicMessage || 'Resource is referenced by related records';}
 if(status>=500){console.error(err);message='Internal server error';}
```

```js
import {AppError} from './error-handler.js';
export const queryParser = () => (req,res,next) => {
 function positive(value,fallback){if(value===undefined)return fallback;if(typeof value!=='string'||! /^[1-9]\d*$/.test(value)||!Number.isSafeInteger(Number(value)))throw new AppError('Invalid pagination',400,'VALIDATION_ERROR');return Number(value);}
 const page=positive(req.query.page,1),limit=Math.min(positive(req.query.limit,10),100),offset=(page-1)*limit;
 if(!Number.isSafeInteger(offset))throw new AppError('Page too large',400,'VALIDATION_ERROR');
 req.pagination={page,limit,offset};next();
}
```

```js
import * as repo from '../repositories-$id/repository.js';
import mapper from '../mappers-$id/entity-dto-mapper.js';
import {AppError} from '../middlewares-$id/error-handler.js';
const required=['sku','name','brand_id','category','price','ram_gb','storage_gb','color'];
const writable=[...required,'stock_quantity','status','release_date'];
function fail(message){throw new AppError(message,400,'VALIDATION_ERROR');}
function object(body){if(!body||typeof body!=='object'||Array.isArray(body))fail('JSON object required');}
function pick(body){object(body);const data={};for(const key of writable)if(Object.hasOwn(body,key))data[key]=body[key];return data;}
function validate(p){
 for(const key of required)if(p[key]===undefined||p[key]===null)fail(`Field '${key}' is required`);
 for(const key of ['sku','name','category','color','status'])if(typeof p[key]!=='string'||!p[key].trim())fail(`Invalid ${key}`);
 for(const key of ['brand_id','ram_gb','storage_gb'])if(!Number.isSafeInteger(p[key])||p[key]<=0)fail(`Invalid ${key}`);
 if(typeof p.price!=='number'||!Number.isFinite(p.price)||p.price<0)fail('Invalid price');
 if(!Number.isSafeInteger(p.stock_quantity)||p.stock_quantity<0)fail('Invalid stock_quantity');
 if(p.release_date!==null){const s=p.release_date,d=new Date(s+'T00:00:00Z');if(typeof s!=='string'||!/^\d{4}-\d{2}-\d{2}$/.test(s)||!Number.isFinite(d.getTime())||d.toISOString().slice(0,10)!==s)fail('Invalid release_date');}
 return p;
}
async function existing(id){const row=await repo.findOne(id);if(!row)throw new AppError(`Product '${id}' was not found`,404,'PRODUCT_NOT_FOUND');return row;}
export const getBrands=()=>repo.brands();
export async function getBrand(id){const row=await repo.brand(id);if(!row)throw new AppError('Brand not found',404,'BRAND_NOT_FOUND');return row;}
export async function getAllObjects(pagination){return mapper.maps(await repo.findAll(pagination),'summary');}
export async function getObject(id){return mapper.toDetailDTO(await existing(id));}
export async function createObject(body){const data=validate({stock_quantity:0,status:'AVAILABLE',release_date:null,...pick(body)});return mapper.toDetailDTO(await repo.create(data));}
export async function updateObject(id,body){
 const old=await existing(id);object(body);for(const key of required)if(!Object.hasOwn(body,key))fail(`Field '${key}' is required`);const patch=pick(body);if(!Object.keys(patch).length)fail('No writable fields');
 const data=validate({...pick(old),...patch});return mapper.toDetailDTO(await repo.update(id,data));
}
export async function removeObject(id){await existing(id);await repo.remove(id);}
```
