# ฐานกลางภาคชุดเดียว — เริ่มตรงนี้

เปิด [คู่มือเลือกตามโจทย์](../../START-TREE.html) ในเบราว์เซอร์ หรือ [ฉบับMarkdown](../../TREE/start.md)
ใช้ชื่อไฟล์ในโปรเจกต์นี้ตลอด ไม่เปลี่ยนไปใช้ZIPWeek8เมื่อทำโจทย์Week8

## ถ้าทดลองโจทย์ Week8
1. เปิดสเปกWeek8ของคุณไว้ข้าง ๆ ใช้SQLในdatabase/init-database.sqlเพื่อตั้งฐานฝึกmobile_distributorตามขั้นเตรียม ห้ามรันซ้ำโดยไม่ตรวจDROP/TRUNCATE
2. ตั้งsrc/configs-$id/db-config.jsให้เชื่อมฐานของเครื่อง ตรวจการเชื่อมก่อน
3. ข้อ2.1ทำโดยเพิ่มrouteในapp.jsตามคู่มือ ไม่ต้องเพิ่มrepository/service
4. ก่อนทำCRUDครั้งแรก เปิด [เตรียมโครงMobile](../../START-TREE.html#base-mobile) ทำครั้งเดียวและเก็บroute2.1ไว้
5. เลือกข้อแบรนด์/สินค้า แล้วเพิ่มเฉพาะก้อนที่หน้าคำตอบระบุ ทดสอบข้อใหม่และข้อก่อนทุกครั้ง
6. รันด้วยnode src/app.js ไม่ใช้test-service.jsที่มีคำสั่งทดลองลบข้อมูล

## งานอื่น
ใช้สำเนาใหม่ของเทมเพลตกลางภาคเดิม แล้วตั้งDB/helperตามสเปกงานนั้น ไม่เอาhelperของหลายรูปแบบresponseมาทับกัน
ดู [แนวทางฐานเดียว](../../12-SINGLE-TEMPLATE.md) และ [ผลตรวจคำตอบแบบทีละข้อ](../../13-RECIPE-VERIFY.md)
หากต้องการฝึกง่ายที่สุดก่อน มี [ตัวอย่างGET/countries](../../01-FIRST-TASK.md) ให้ทำบนSakilaแยกเป็นงานฝึก
