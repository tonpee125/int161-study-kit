# INT161 — เริ่มอ่านตรงนี้

## เปิดสรุปบทเรียน

**ดาวน์โหลด ZIP → แตกไฟล์ → เปิด `00-เปิดสรุปบทเรียน.html` ด้วย Brave / Chrome / Edge → กดปุ่ม “เปิดสรุปบทเรียน”**

หรือเปิด [index.html](index.html) ในเบราว์เซอร์ หากเปิดจาก GitHub โดยตรงจะเห็นโค้ด HTML ต้องดาวน์โหลดและแตกไฟล์ก่อน

ไม่ต้องติดตั้ง dependency หรือเปิด Live Server เพื่ออ่านเอกสาร ใช้ `index.html` เป็นหน้าหลักได้หากใช้เซิร์ฟเวอร์ในเครื่อง

- [สรุปบทเรียน](START-TREE.html)
- [ฉบับ Markdown](TREE/start.md)
- [ขั้นตอนเริ่มฝึก](01-FIRST-TASK.md)
