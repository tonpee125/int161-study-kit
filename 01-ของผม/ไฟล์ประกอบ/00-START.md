# เริ่มจากเทมเพลตครูจริง
ตอนนี้ใช้ midterm-exam-esm-template.zip เป็นฐาน ชื่อไฟล์/โฟลเดอร์ตรงครู ไม่มี server.js หรือ -guide

## เริ่มเลือกโจทย์ตรงนี้ก่อน
เปิด [START-TREE.html](START-TREE.html) ด้วยเบราว์เซอร์ (ดับเบิลคลิกไฟล์ได้ ไม่ต้องรันserver)
เลือกคำตอบตามข้อความที่เห็นในโจทย์ทีละหน้า ทุกคำตอบหลักใช้เทมเพลตกลางภาคชุดเดียว โจทย์Week8/Week6เป็นข้อกำหนดและSQL ไม่เปลี่ยนไปใช้ZIPตั้งต้นของงานนั้น
ปลายทางแสดงเฉพาะฟังก์ชันและrouteของข้อที่เลือก พร้อมตำแหน่งเพิ่ม/แทนและวิธีทดสอบ ไม่คัดทั้งโปรเจกต์ทับ
เป็นเอกสารลิงก์ออฟไลน์ ไม่มีJavaScript/AI และไม่มีระบบอ่านโจทย์อัตโนมัติ
ถ้าต้องการอ่านเป็นMarkdown ใช้ [TREE/start.md](TREE/start.md); ไฟล์รวมอยู่TREE-ALL.txt
ยังไม่ต้องเปิดWebStormเพียงเพื่ออ่านต้นไม้ เปิดโปรเจกต์เมื่อถึงหน้าลงมือทำ

## ทำขั้นแรกเท่านั้นก่อน
1. WebStorm → File → Open
2. เลือก Desktop/INT161/INT161-Teacher-Template/01-WORK/node-express-esm-template
3. ต้องเห็น package.json และ src/configs-$id, repositories-$id, services-$id, routes-$id, mappers-$id, middlewares-$id
4. ถ้าแจ้ง Install dependencies กด npm install ขณะยังมีเน็ตและอยู่ในช่วงที่อนุญาต
5. เปิดต้นไม้ เลือกโจทย์ที่กำลังฝึก แล้วกดเตรียมโครงCRUDครั้งแรกของงานนั้น หากทำข้อ2.1แล้วให้เก็บrouteไว้

## โฟลเดอร์มีหน้าที่อะไร
- 00-ORIGINAL: ไฟล์ครูไว้เทียบ ไม่แก้; ZIPต้นฉบับเก็บแยกครบ
- 01-WORK: สำเนาเทมเพลตครูสำหรับคุณลงมือ ไม่ใช่โปรเจกต์รูปแบบใหม่
- TREE: ขั้นตอนเพิ่มทีละข้อบนเทมเพลตกลางภาค ใช้เป็นคำตอบหลัก
- 02-ANSWERS: โค้ดตัวอย่างครบโปรเจกต์ไว้เทียบ ไม่ใช้คัดapp.jsทับเมื่อทำทีละข้อ
- 03-DECISION-TREE.md: อ่านโจทย์แล้วเลือกทาง
- 04-ADD-RESOURCE.md: เพิ่มข้อถัดไปโดยเก็บข้อเดิม
- 05-POSTMAN.md: ตรวจ method/URL/body/status
- 06-RECOVERY.md: หาอาการเสีย
- 07-AUDIT.md: ส่วนที่ครูเว้นไว้และสิ่งที่เราแก้
- 08-VERIFY.md: ผลตรวจชุดใหม่นี้ แยกจากผลทดสอบชุดเก่า

โฟลเดอร์ -$id คือตัวอักษรตามชื่อใน ZIP จริง อย่ารีบแทนชื่อ หากข้อสอบสั่งเปลี่ยนเป็นรหัสให้เปลี่ยนทั้งโฟลเดอร์และทุกimportพร้อมกัน
อย่าเปิด examples/sakila ของชุดเก่าต่อ และอย่ารัน test-service.js เพราะมีคำสั่งลบข้อมูลทดลองของครู
คู่มือเป็นเอกสารอ้างอิงและsourceที่อ่านเอง ไม่มี AI หรือระบบรับโจทย์อัตโนมัติ กติกาข้อสอบจริงเป็นหลัก
