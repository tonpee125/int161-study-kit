# การตรวจข้อกำหนดที่ยังไม่ชัดเจน

จุดสังเกตในข้อกำหนด: ชื่อข้อ, Method / URL และตัวอย่างข้อมูลที่เกี่ยวข้อง
คัดบรรทัดโจทย์ที่มี Method/URI, Request Body, Response Body และเงื่อนไขไว้ใน02-READ-QUESTION.md ดูSQLและตัวอย่างก่อนตัดสิน ถ้าโจทย์ขัดกันหรือไม่ระบุเงื่อนไขสำคัญ ให้ถามครู/ผู้คุมผ่านช่องทางที่อนุญาต เอกสารธรรมดาอ่านใจโจทย์ใหม่ไม่ได้ และไม่ควรเลือกเฉลยผิดเพียงเพื่อเดินต่อ
