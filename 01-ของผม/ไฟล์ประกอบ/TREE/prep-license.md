# ตั้งค่า JetBrains License ตามภาพสไลด์ครู

ข้อมูลนี้ถอดจากภาพที่ผู้ใช้ให้ ไม่ใช่การตรวจสอบสิทธิ์ปัจจุบันของบัญชี
1. ลงทะเบียนบัญชี JetBrains ด้วยอีเมล SIT ตามหมายเหตุในสไลด์ก่อน
2. เปิดหน้าจัดการ License ของWebStorm เช่น Help → Register / Manage License (ชื่อเมนูอาจต่างตามเวอร์ชัน)
3. ถ้าใช้สิทธิ์มหาวิทยาลัยตามภาพ เลือก Paid license → License server
4. ช่อง Server address ใส่:
```text
https://sit.fls.jetbrains.com
```
5. กด Test Connection หรือ Activate ตามหน้าที่แสดง และลงชื่อเข้าบัญชีที่มีสิทธิ์เมื่อระบบร้องขอ
ถ้ามีLicenseใช้งานได้อยู่แล้ว ไม่ต้องตั้งใหม่ ภาพมีวันหมดอายุเก่า จึงไม่ใช้วันในภาพยืนยันสิทธิ์ของวันนี้ หากยืนยันไม่ได้ให้ติดต่อผู้ดูแลสิทธิ์ของคณะ
เตรียมการยืนยันสิทธิ์ที่ต้องใช้อินเทอร์เน็ตให้เสร็จก่อนช่วงสอบที่ห้ามต่อเน็ต
