# 1.1.2 การแบ่งหน้าและค่าเริ่มต้น

จุดสังเกต: คำว่า default / ค่าเริ่มต้น ใน Query Parameters และตัวอย่าง response
ค่าเริ่มต้นคือค่าที่แอปใช้เมื่อผู้เรียกไม่ได้ส่งมา เช่น page เริ่มที่1
ถ้าใช้ใบงาน Week8 “รายการสินค้าแบบแบ่งหน้าและแปลง DTO” ชุดหลักอยู่ตัวเลือกแรก; ค่าlimit10เป็นค่าที่โค้ดตัวอย่างนี้ใช้ ให้แก้หากโจทย์จริงกำหนดต่าง
ถ้าโจทย์ไม่กำหนดพฤติกรรมเมื่อขาดquery ไม่ควรเดาว่าเหมือนกันทุกงาน
ตัวอย่างโจทย์: ใบงาน Week8 ระบุ page เริ่มที่ 1 และให้ทำรายการสินค้าแบ่งหน้า → อ่านชุด “ยังแบ่งหน้า โดยใช้ค่าเริ่มต้น”; ถ้าข้อกำหนดเขียนว่าไม่ส่ง query ให้คืนทั้งหมด → เลือกทางคืนทั้งหมดแทน
