# 1.1 การอ่านข้อมูลหลายรายการ

จุดสังเกต: ชื่อข้อ, Query Parameters และตัวอย่าง Response Body
ถ้าเห็น “รายการสินค้าแบบแบ่งหน้าและแปลง DTO” หรือมี page, limit, pagination ให้เลือกแบ่งหน้า
ถ้าเป็น “รายการแบรนด์ทั้งหมด” และไม่มีคำสั่งแบ่งหน้า ให้เลือกทั้งหมด ไม่ต้องรู้ว่า DTO หมายถึงอะไรเพื่อเลือกข้อนี้
ตัวอย่างโจทย์: “รายการสินค้าแบบแบ่งหน้าและแปลง DTO” พร้อม page/limit → เลือก “มีแบ่งหน้า”; “รายการแบรนด์ทั้งหมด” ไม่มีเงื่อนไขแบ่งหน้า → เลือก “แสดงทั้งหมด”
