# ส่วนประกอบของ URL: Path และ Query

จุดสังเกตในข้อกำหนด: ชื่อข้อ, Method / URL และตัวอย่างข้อมูลที่เกี่ยวข้อง
/products/12 คือรหัสในpath; /products?page=2&limit=10 คือquery; JSONที่ส่งในแท็บBodyคือbody เครื่องหมาย :id ในโจทย์เป็นชื่อช่อง ไม่ใช่คำที่ส่งจริง สำหรับ /api/รหัสนักศึกษา/products/12 ค่าprefixรหัสนักศึกษากับรหัสสินค้า12เป็นคนละอย่าง
