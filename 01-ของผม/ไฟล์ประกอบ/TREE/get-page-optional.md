# 1.1.4 รายการทั้งหมดและการเลือกมุมมองข้อมูล

จุดสังเกต: Query Parameters ว่ามี view=summary หรือ view=detail หรือไม่
summary = ข้อมูลสรุป, detail = รายละเอียดมากขึ้น เช่น brandName
ชุดนี้เป็นทางเลือกสำหรับสเปกที่ไม่ส่งทั้งpage/limitแล้วคืนทั้งหมด ไม่ใช่ใช้แทนใบงานWeek8โดยอัตโนมัติ
ตัวอย่างโจทย์: ข้อกำหนดมี view=summary หรือ view=detail และไม่ส่ง page/limit ให้คืนทั้งหมด → เลือกชุด Mobile แบบไม่ส่ง query คืนทั้งหมด
