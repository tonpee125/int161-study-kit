# การเตรียมเทมเพลตและการเชื่อมต่อฐานข้อมูล

จุดสังเกตในข้อกำหนด: ชื่อข้อ, Method / URL และตัวอย่างข้อมูลที่เกี่ยวข้อง
เปิด 01-WORK/node-express-esm-template ที่เห็น package.json และsrc นี่เป็นสำเนาไฟล์ครู ติดตั้งdependenciesไว้ในเครื่องนี้แล้ว หากแตกZIPไปอีกเครื่องต้องติดตั้งขณะอนุญาตให้ต่อเน็ต เปิดsrc/configs-$id/db-config.js ใส่ค่าของMySQLเครื่องนั้น แล้วตรวจตารางจริง รันด้วย node src/app.js ไม่มี npm start ในpackageครู ห้ามRun test-service.js ที่มีคำสั่งลบรหัส26
