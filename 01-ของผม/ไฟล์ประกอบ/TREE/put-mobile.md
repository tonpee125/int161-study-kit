# 3.1 การส่งข้อมูลครบและการส่งเฉพาะช่องที่แก้ไข

จุดสังเกต: เงื่อนไขข้อแก้ไข, ตัวอย่าง Request Body และ request ในตัวตรวจที่ครูให้
ส่งบางช่อง = เช่นส่ง name,price,stock_quantity โดย skuเดิมยังอยู่
ส่งครบ = โจทย์บังคับให้ส่งrequiredครบทุกครั้ง แม้ช่องนั้นไม่เปลี่ยน
ใบงานWeek8ที่ตรวจไม่อธิบายเรื่องนี้ละเอียด แต่ตัวตรวจซ้อมส่งเพียง3ช่อง จึงเตรียมชุดรับบางช่องไว้เป็นชุดหลัก; นี่เป็นหลักฐานจากตัวตรวจ ไม่ใช่กฎของPUTทุกโจทย์
ตัวอย่างโจทย์: ตัวตรวจซ้อมส่งแค่ name, price, stock_quantity → เลือกส่งเฉพาะช่องที่แก้; ถ้าโจทย์บังคับส่งช่องจำเป็นครบทุกครั้ง → เลือกส่งครบ
