# พื้นฐาน HTTP Method และการอ่าน Endpoint

จุดสังเกตในข้อกำหนด: ชื่อข้อ, Method / URL และตัวอย่างข้อมูลที่เกี่ยวข้อง
ดูบรรทัด Method & URI, Endpoint หรือหัวข้อ [GET] ก่อน ตัวอย่าง GET /products คืออ่าน, POST /products คือเพิ่ม, PUT /products/:id คือแก้, DELETE /products/:id คือลบ คำว่า :id ให้แทนรหัสจริงเมื่อส่ง Postman ถ้าครูไม่ได้ระบุ Method จริง ๆ ให้จดว่าไม่ระบุและสอบถามตามกติกา ไม่เดาจาก Body อย่างเดียว
