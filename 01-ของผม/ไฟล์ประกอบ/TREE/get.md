# บทที่ 1 การอ่านข้อมูลด้วย GET

จุดสังเกต: ชื่อหัวข้อและ URL ในโจทย์
“รายการแบรนด์ทั้งหมด” + /brands = หลายรายการ
“ข้อมูลแบรนด์ตามรหัส ID” + /brands/:id = หนึ่งรายการ
เครื่องหมาย :id คือช่องให้แทนรหัสจริง เช่น /brands/1 ไม่ใช่คำที่พิมพ์ส่งตามตัวอักษร
ตัวอย่างโจทย์: “รายการแบรนด์ทั้งหมด” → เลือก “ดูหลายรายการ” ส่วน “ข้อมูลแบรนด์ตามรหัส ID” → เลือก “ดูหนึ่งรายการตามรหัส”
