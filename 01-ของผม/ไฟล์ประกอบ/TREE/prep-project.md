# 1. เปิดโปรเจกต์และแยกเทมเพลตที่ใช้

WebStorm → File → Open → เลือก Desktop/INT161/INT161-Teacher-Template/01-WORK/node-express-esm-template ที่เห็นpackage.jsonกับsrc
ชุดนี้เป็นเทมเพลตกลางภาคสำหรับใช้ทำทุกโจทย์ในคู่มือ ไม่ใช้Week8-Tryเป็นฐานของคำตอบชุดใหม่นี้
หากเคยเริ่มงานในWeek8-Try เก็บไว้เป็นสำรอง อย่าคัดโค้ดทับกัน เปิดสำเนากลางภาคอีกชุดเพื่อฝึกจากต้น
โจทย์และSQLWeek8ใช้เป็นข้อกำหนด/ข้อมูลเท่านั้น ชื่อไฟล์ที่แก้ยังเป็น repository.js / service.js / route.js ในโฟลเดอร์-$id
ห้ามRun test-service.js ที่มีคำสั่งทดลองลบข้อมูล
