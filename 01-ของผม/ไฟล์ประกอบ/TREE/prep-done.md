# พร้อมเริ่มทำโจทย์

ตรวจทีละข้อก่อนเริ่ม:
1. เปิดโปรเจกต์ที่มีpackage.jsonและsrcถูกชุด
2. Node/npmใช้ได้และdependenciesครบ
3. WebStorm Test Connectionผ่าน
4. มีฐานและตารางตามSQLของงาน
5. db-config.jsใช้ค่าconnectionตรงเครื่อง
6. node src/check-db.jsได้connected1และชื่อฐานถูก
7. node src/app.jsเปิดExpressได้ ไม่รันหลายinstance
เมื่อครบแล้วจึงเลือกข้อแรกของงาน ทำแล้วใช้PostmanตรวจAPIจริง; ไม่ต้องทำขั้นติดตั้งหรือนำเข้าSQLซ้ำทุกข้อ
