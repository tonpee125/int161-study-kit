# 1.2.1 การค้นด้วย country_id และ actor_id

จุดสังเกตในข้อกำหนด: ชื่อข้อ, Method / URL และตัวอย่างข้อมูลที่เกี่ยวข้อง
ใช้WHEREชื่อคีย์จริง ไม่ใช่idในSQL แม้URLจะเขียน:id
ตัวอย่างโจทย์: “ค้นประเทศตาม country_id” → เลือก country; “ค้นนักแสดงตาม actor_id” → เลือก actor
