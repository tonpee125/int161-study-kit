ดาวน์โหลดโปรเจกต์พร้อมเปิดใน WebStorm

ชุดเริ่มพร้อมใช้ · ฐานข้อมูลใดก็ได้

ชุดตัวอย่าง Week 8 · API ครบทุกข้อ

แตก ZIP → เปิดโฟลเดอร์ใน WebStorm → เปิด 00-เปิดวิธีใช้.html มี config, error handling และ Postman ให้แล้ว ต้องตั้งฐานข้อมูลกับรหัสของคุณก่อนใช้

1. เปิดโปรเจกต์ให้ถูกก่อน

  1. กด ดาวน์โหลดเทมเพลตครู → แตก ZIP เป็นโฟลเดอร์ฝึกใหม่ เก็บต้นฉบับไว้
  2. เปิด WebStorm → File → Open → เลือกโฟลเดอร์ที่เห็น package.json และ src พร้อมกัน
  3. เปิด Terminal ด้วย Alt+F12 แล้วเตรียมแพ็กเกจขณะใช้อินเทอร์เน็ตได้:
    npm ci
    ถ้าใช้ชุดในเครื่องนี้ เปิด 01-WORK/node-express-esm-template และตรวจว่าแพ็กเกจติดตั้งครบแล้ว
  4. เปิด Database → + → Data Source → MySQL ใส่ host/port/user/password ของเครื่อง → Test Connection → OK
  5. นำเข้า SQL ที่โจทย์ให้ แล้วดูชื่อตารางและคีย์ก่อนเลือกสูตร อย่ารันสคริปต์ล้างฐานซ้ำหลังเริ่มเพิ่มข้อมูล

หน้านี้ประกอบโค้ดจากตัวอย่างที่เตรียมไว้ ไม่ใช้ AI และไม่ส่งข้อมูลออกอินเทอร์เน็ต

2. กรอกค่าของงานนี้

เทมเพลตกลางภาคที่ตรวจไม่มี error-handler.js คู่มือนี้สร้างให้ และวางหลัง routes อัตโนมัติ

เลือกชนิดงานก่อนเริ่มสะสม รหัสผ่านและ Secret Key จะไม่ถูกบันทึกไว้หลังโหลดหน้าใหม่

3. เลือกข้อ → กรอกค่า → ดูโค้ด

โค้ดรวม

    เก็บแผนไว้ทำต่อ

    วิธีง่าย: แตก ZIP → เปิดโฟลเดอร์ใน WebStorm → Terminal: npm ci → node src/app.js

    ไฟล์ไหนต้องสร้าง / แทน · เช็กทีละไฟล์

    ใช้ในสำเนาโปรเจกต์ฝึก โค้ดนี้เป็นไฟล์เต็ม ไม่วางต่อท้ายไฟล์เดิม

    หรือคัดลอกทีละไฟล์ด้านล่างไปใส่โปรเจกต์เดิม เก็บงานที่แก้เองก่อนวางทับ

    นำโค้ดไปใช้ใน WebStorm
    1. กด ดาวน์โหลดโค้ดรวม ZIP แล้วแตกไฟล์ในโฟลเดอร์ชั่วคราว
    2. คัดลอกโฟลเดอร์ src ที่ได้ ไปวางในสำเนาเทมเพลตฝึกที่เปิดอยู่ ให้ตรงชื่อไฟล์ หากมีงานแก้เองให้เก็บส่วนนั้นก่อนแทนที่
    3. ใน Terminal ของโปรเจกต์ รัน node src/app.js ถ้าแอปเดิมยังเปิดอยู่ให้ Ctrl+C ก่อน
    4. ใช้ Postman ทดสอบข้อนี้ จากนั้นกด ทำข้อต่อไป ในหน้านี้ เมื่อเพิ่มข้อใหม่ให้ใช้ไฟล์รวมฉบับล่าสุด

    ถ้าใช้ไฟล์จาก ZIP ครบชุด: รัน npm ci ก่อนครั้งแรก แล้ว node src/app.js

    ทดสอบข้อนี้ใน Postman
    บันทึกไฟล์ → หยุดแอปเดิมด้วย Ctrl+C → node src/app.js แล้วส่ง request ของข้อนี้และข้อก่อนซ้ำ
