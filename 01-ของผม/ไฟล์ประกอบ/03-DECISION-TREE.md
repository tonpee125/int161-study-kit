# เลือกโจทย์บนเทมเพลตกลางภาคชุดเดียว
เปิด [หน้าเลือกหลัก](TREE/start.md) หรือ START-TREE.html ไม่มีขั้นให้สลับZIPตามชนิดโจทย์

1. ดูMethod/URL/Body/Responseในโจทย์แล้วเลือกGET/POST/PUT/DELETE
2. เลือกเงื่อนไขย่อยจากตัวอย่างที่ตรงกับโจทย์
3. ถ้าเป็นCRUDข้อแรกของงาน เตรียมโครงครั้งเดียวตามรูปแบบข้อมูลของงานนั้น:
   - [Mobile / Week8](TREE/base-mobile.md)
   - [Classicmodels / Week6](TREE/base-classic.md)
   - [Sakila country / actor](TREE/base-sakila.md)
4. คัดเฉพาะก้อนฟังก์ชันและrouteที่คำตอบระบุ เก็บข้อก่อนหน้า
5. ทดสอบPostmanตามสัญญาของข้อใหม่ แล้วตรวจข้อก่อนซ้ำ

ข้อ2.1ไม่ต้องเตรียมชั้นฐานข้อมูล ทำโดยเพิ่มrouteในapp.jsตาม [วิธีทำเฉพาะข้อ](TREE/empty-identity.md)
การเปลี่ยนโจทย์ทั้งงานที่ใช้DB/responseคนละรูปแบบควรใช้สำเนาใหม่ของเทมเพลตกลางภาคเดิม ไม่ใช่รวมทุกฐานไว้ในโปรเจกต์เดียวโดยไม่ออกแบบ
