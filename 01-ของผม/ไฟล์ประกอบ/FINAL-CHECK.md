# ผลตรวจชุดส่งต่อ

ตรวจวันที่ 22 ตุลาคม 2026

- หน้าอ่าน 160 หน้าแสดงผลและเข้าถึงปุ่มนำทางได้
- ตรวจลิงก์ไฟล์และ anchor ในหน้าหลัก 3,090 ลิงก์ ไม่พบปลายทางหาย
- ค้นหา 151 รูปแบบ รวมข้อความจากสเปก Week 8 ผ่าน
- ชุดประกอบโค้ด 56 แบบ: 101 snapshots, JavaScript 863 modules ตรวจ syntax ผ่าน
- ตัวอย่างเดียวต่อสูตร 28 สูตร กรอกตัวอย่างและสะสมโค้ดผ่าน
- ทดสอบ Week 8 8 ขั้น และตัวอย่างทั่วไป 3 ขั้นในเบราว์เซอร์ผ่าน
- ทดสอบแก้ URL ชน, ยกเลิก, ย้อนดูโค้ด, เปิดแผนเดิม, คัดลอกและดาวน์โหลดผ่าน
- เอกสาร Week 8 มี 4 สเปก, 8 endpoints, โค้ดตัวอย่าง 66 ก้อนตรวจ syntax ผ่าน
- เปิดชุด READY-STARTER และ READY-WEEK8 แล้วเรียก /health ได้ 200
- ตรวจหน้าเว็บบนจอ 390px และ 1366px ไม่มีเนื้อหาล้นแนวนอนในหน้าหลักที่ทดสอบ
- ไม่พบการเรียกเครือข่ายภายนอกระหว่างทดสอบหน้าเว็บ

## ขอบเขต
รอบนี้ตรวจ UX ลิงก์ โค้ดประกอบ และเซิร์ฟเวอร์ health ไม่ได้เชื่อม MySQL ของผู้ใช้หรือรันคำสั่งแก้ข้อมูลในฐานผู้ใช้ การทำโจทย์ใหม่ต้องเทียบ schema, validation และ response กับสเปกจริง

ของเพื่อนเก็บเป็นต้นฉบับ เพิ่มเฉพาะหน้าเปิดและปุ่มนำทาง ไม่ได้แก้โค้ดเพื่อนให้เป็นเฉลยของครู

## ตรวจส่งต่อรอบสุดท้าย
- แก้ลิงก์หัวข้อ GUIDE และคู่มือย่อยของเพื่อนแล้ว เปิดเอกสารต้นฉบับในหน้าอ้างอิงได้ครบ
- แตก ZIP ลงโฟลเดอร์ใหม่ ทดสอบเปิดของเรา → เพื่อน → หัวข้อย่อย → กลับของเราผ่าน
- ตรวจ ZIP 4 ชุด CRC ผ่าน ไม่พบ .env จริงหรือไฟล์ private key ตามชื่อมาตรฐาน
- ZIP รวมตรงกับไฟล์ในโฟลเดอร์ส่งต่อ

## ทดสอบเส้นทางมือใหม่เพิ่มเติม
- เริ่มจากหน้าแรก 3 แบบ: ทั่วไป / Week 8 / Week 6 แล้วดาวน์โหลดโค้ดและเปิดทำต่อหลังโหลดใหม่ผ่าน
- ทดสอบกรอกชื่อตารางผิดและค้นไม่พบ: ไม่เพิ่มข้อที่เสีย และแจ้งใกล้ปุ่ม
- เพิ่มลิงก์เทมเพลตครูตรงขั้นแรก และย้ายปุ่ม ZIP ไว้ก่อนกล่องโค้ด
- เพิ่มคำบอกแหล่งค่าฐานข้อมูลและ Student Profile; Secret Key ที่ไม่ได้จำไว้แสดงช่องว่าง
- คืน .env.example ของเพื่อนเข้า ZIP เพื่อทำตามคู่มือได้ โดยไม่รวม .env จริง
- เรียก API จริงกับ MySQL แยกพอร์ต 33071: ชุดครู 63 ข้อ, สูตรทั่วไป 117 assertions, สะสม 14 ขั้น 86 assertions ผ่าน
- ปิดเซิร์ฟเวอร์ทดสอบแล้ว ไม่แก้ฐานข้อมูลปกติพอร์ต 3306

นี่เป็นการทดสอบระบบและจำลองขั้นตอน ไม่ใช่ผลทดลองกับผู้ใช้มือใหม่จริง จึงยังไม่รับประกันว่าทุกคนจะทำเองได้โดยไม่ติดขัด

## ตรวจใหญ่: กรณีขอบเพิ่มเติม
- แยกคีย์และช่องชื่อของตารางแม่ออกจากตารางลูกใน JOIN / สูตรรวม
- URL รายการแม่และรายการลูกปรับแยกได้ในสูตร nested / เพิ่มรายการลูก
- ทดสอบฐาน publishers/ books ที่ใช้ publisher_id / book_id และ publisher_name / title ต่างกันจริง ผ่าน 11 checks รวมไม่พบแม่และราคา 0
- ทดสอบ SQL สูตรทั่วไป 117 assertions และสะสม 14 ขั้น 86 assertions ผ่านหลังแก้ engine
- เปลี่ยนสูตรหรือแก้ค่าเมื่อขึ้น URL ซ้ำ จะล้างตัวเลือกที่ค้าง ป้องกันแทนข้อด้วยสูตรเก่า
- กลับมาทำต่อจำ mapping ข้อก่อน; เริ่มชุดใหม่รีเซ็ต mapping ชัดเจน
- ตรวจทุกสูตรทั่วไปและ identity บนจอ 320px ผ่าน แก้ URL ยาวไม่ให้ดันหน้าล้น
- ทดสอบเส้นทางมือใหม่ 3 แบบ, การดาวน์โหลด, ค้นไม่พบ, กรอกผิด และการเก็บแผน

ขอบเขตยังเป็นการจำลองการใช้งานและตรวจระบบ ไม่ใช่ผลศึกษากับผู้ใช้มือใหม่จริง
